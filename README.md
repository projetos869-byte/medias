# medias

Portal de consulta individual de médias.

## Funcionalidades

- Login por matrícula e senha.
- Leitura de planilhas Excel no navegador.
- Dashboard responsivo para celular e desktop.
- Geração de senhas pelo VBA.
- Integração preparada para PostgreSQL Neon.

## Segurança

Arquivos CSV, planilhas, credenciais e variáveis de ambiente não são versionados.
As senhas devem ser armazenadas somente como hash.
